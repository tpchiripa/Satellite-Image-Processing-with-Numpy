# Satellite Image Processing with NumPy

This project demonstrates basic satellite image processing using Python’s NumPy and imageio libraries on a sample wildfire satellite image from the WIFIRE project.

## Overview

- Loaded a multi-layer satellite image as a NumPy array.
- Explored pixel-level image manipulation by accessing and modifying individual color channels.
- Applied boolean masks to selectively alter image regions based on color thresholds.
- Visualized the original and modified images using matplotlib.

## Key Concepts

- Image as multidimensional arrays.
- Channel-wise image filtering.
- Logical operations and masking for image processing.
- Basic visualization of satellite data.

## Data Source

The sample image used is from the [WIFIRE Project](https://wifire.ucsd.edu/), which provides wildfire monitoring using integrated satellite and sensor data.

## Libraries Used

- `numpy`
- `imageio`
- `matplotlib`
